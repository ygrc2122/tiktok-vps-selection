## 原生 IP 和家宽 IP 不是一回事

TikTok 风控看的核心指标之一是 IP 属性。机房 IP（IDC IP）来自云服务商的数据中心段，平台很容易判定这不是普通用户家的网络；原生家宽 IP、双 ISP 住宅 IP 来自当地宽带运营商，属性更接近真实住户，账号注册和起号阶段的通过率差别主要出在这里。

但“原生 IP”这个词被用得很松。原生 IP 只说明 IP 注册地和服务器所在国一致，不代表它是家宽。WePC 的套餐页把三种情况分开标注：原生 IPv4、原生家宽 IPv4、原生 IDC IPv4。英国 TikTok 专线写的是“英国原生非家宽 IPv4”，英国原生家宽_TK专用写的才是家宽。这两款差 4 澳元，用途也不一样：只发视频、做冷启动，原生非家宽够用；要长期养号、开直播，家宽属性更稳。

另外一条底线是独享。WePC 的 TikTok 系列标配独立静态 IPv4，一台机器一个 IP，不与他人共用。共享 IP 上挂几十个号，行为特征一集中，平台照样识别。
